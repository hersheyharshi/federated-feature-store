# Glossary (plain-English, in our own words)

Add or rewrite each definition so that either of us could explain it to a friend.

| Term | Our definition |
|---|---|
| Federated learning | Hospitals each train on their own records and share only what the model learned, never the records. |
| Differential privacy | Adding measured noise so nobody can tell whether one particular patient was in the data. |
| Epsilon (privacy budget) | A number for how much privacy we are spending. Smaller means more privacy and less accuracy. |
| Feature store | A shared, versioned list of the inputs the model uses and how they are prepared. |
| Catastrophic forgetting | When a model learns something new and loses what it knew before. |
| Concept drift | When the real-world relationship between inputs and outcomes changes over time. |
